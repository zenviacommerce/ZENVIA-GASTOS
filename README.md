# ZENVIA Gastos

Aplicación interna de ZENVIA COMMERCE para centralizar facturas de gastos, escanear documentos desde móvil, controlar gasto trimestral, gestionar proveedores y mantener el histórico de costes de productos.

## Stack

- React + TypeScript + Vite
- Supabase Auth, PostgreSQL y Storage privado
- Vercel

## Funcionalidades iniciales

- Dashboard de gastos e IVA
- Subida de facturas PDF
- Captura con cámara móvil y generación de PDF
- Proveedores y categorías
- Inventario de productos y último coste
- Histórico de precios de compra
- Detección de duplicados por hash
- Exportación trimestral de facturas
- Base preparada para integración automática con Gmail
